# Contributing

Thank you for helping improve this resource.

## Inclusion criteria

A proposed item should:

- Be directly useful for microbial pangenomics or an essential upstream/downstream step.
- Be open source, openly accessible, or an established public data resource.
- Have an official project page and preferably a peer-reviewed primary publication.
- Include a concise description that states what it does, not promotional language.
- Be placed in the most specific relevant category.

## Pull requests

1. Add one item per line or table row.
2. Link to the official repository, documentation, or stable project page.
3. Link to the primary paper in the reading list when one exists.
4. Verify that every new or changed URL resolves before submitting; prefer the project's canonical HTTPS URL when available.
5. Explain why the resource belongs here in the pull-request description.
6. Do not add paywalled commercial services, unmaintained forks, or generic tools unless they have a specific and important pangenomics role.

## Corrections

Tool status changes quickly. Please open an issue or pull request for broken links, renamed projects, superseded resources, inaccurate descriptions, or missing foundational literature.

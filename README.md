 # Awesome Microbial Pangenomics [![Awesome](https://cdn.rawgit.com/sindresorhus/awesome/d7305f38d29fed78fa85652e3a63e154dd8e8829/media/badge.svg)](https://github.com/sindresorhus/awesome) [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A curated list of bioinformatics tools, graph-based framework tools, databases, and pipelines dedicated to **bacterial and microbial pangenomics**.

---

## 🧬 Pangenome Analysis Frameworks

| Tool | Focus / Description | Language / Platform |
| :--- | :--- | :--- |
| [Roary](https://github.com/sanger-pathogens/Roary) | High-speed stand-alone prokaryotic pan-genome pipeline | Perl / Python |
| [Panaroo](https://github.com/gtonkinhill/panaroo) | Graph-based pangenome analysis pipeline for structural variation | Python |
| [PPanGGOLiN](https://github.com/labgem/PPanGGOLiN) | Partitioned pangenome graph analysis for thousands of genomes | Python / C |
| [PanACoTA](https://github.com/gem-pasteur/PanACoTA) | End-to-end module for preparation, annotation, core genome, and trees | Python |
| [Anvi'o](https://github.com/merenlab/anvio) | Comprehensive omics platform with powerful pangenome visualization | Python / C++ |
| [panX](https://github.com/neherlab/pan-genome-analysis) | Analysis and interactive visualization of microbial pangenomes | Python / JS |

## 🕸️ Graph Pangenomics & Alignment

- **[vg](https://github.com/vgteam/vg)** — Variation graph toolkit for mapping reads and calling variants against genome graphs.
- **[odgi](https://github.com/pangenome/odgi)** — Optimized Data structures for Graph Genomics (fast analysis of GFA files).
- **[PGGB](https://github.com/pangenome/pggb)** — PanGenome Graph Builder for pairwise alignment, graph induction, and layout.
- **[Bandage](https://github.com/rrwick/Bandage)** — Interactive GUI tool for visualizing assembly graphs (GFA/FASTG).

---

## 📊 Visualization Tools

- **[FriPan](https://github.com/dr-L/FriPan)** — Web-based interactive bacterial pangenome browser.
- **[Phandango](https://github.com/jameshadfield/phandango)** — Interactive visualization of genome alignments, pangenomes, and phylogenetic trees.
- **[SeqTubeMap](https://github.com/vgteam/sequenceTubeMap)** — Tube-map-style visualizer for graph pangenome alignments.

---

## 🔄 Workflows & Pipelines

- **[nf-core/pangenome](https://github.com/nf-core/pangenome)** — Nextflow pipeline for pangenome graph construction (wfmash, seqwish, smoothxg).
- **[Bactopia](https://github.com/bactopia/bactopia)** — Flexible Nextflow workflow for complete bacterial genome analysis including pangenomics.
